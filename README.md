# claude-plugins

Marketplace de plugins Claude Code personnels.

## Installation

```
/plugin marketplace add adam-elbesri/claude-plugins
/plugin install monitorank@adam-plugins
```

## monitorank

La clé API n'est **pas** dans ce dépôt. Fournir `MONITORANK_API_KEY` en variable d'environnement
(en local : `~/.monitorank-mcp/config.json` fonctionne aussi).
